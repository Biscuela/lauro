# Git Local

## O que é Git 

## Vocabulário:

- ''Repositório'' - Pasta raiz de um git centralizadoras de todos os arquivos de um projeto.

- ''Working Tree'' - Clone local do repositório em git.

- ''Staging'' - Ambiente onde uma versão em desenvolvimento do projeto está rodando em paralelo com a versão em produção (Product). 

- ''Commit'' - Um pacote de mudanças feitas por um contribuidor para o projeto. Essas mudanças sãoenviadas para o repositório via comando push para uma branch especifica do repositório.

- ''Head'' - Não sei o que é. Chuto que é alguma coisa relacionada com cabeçalho.
