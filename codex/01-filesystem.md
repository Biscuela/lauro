# File System

## Vocabulário:

- ''Path'' é o caminho entre sua localização atual no terminal e um destino pretendido. Exemplo: seu/caminho/para/destino/final.txt;

- ''Home'' é o Path para a para a pasta local do usuário. Exemplo: C:\Users\Natan;

- ''CWD'' é o "Current Working Directory". Serve de ponto referencial para definir um Path. Exemplo:Se eu estou em C:\Users e eu quero chegar no arquivo codex/01-filesystem.md, então eu preciso percorrer o Path Natan/lauro/codex/01-filesystem.md. Logo, meu CWD é o ponto de partida (C:\Users).

- ''Root'' é a pasta raiz do disco local. Exemplo: C:\

## Comandos Aprendidos

- ''cd'' - Redireciona o usuário através de um path em relação ao CWD. Os comandos cd ~ ou cd .. servem para voltar à pasta pai. 

- ''ls'' - Lista os filhos deste CWD.
